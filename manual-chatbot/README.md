# 매뉴얼 챗봇 (테스트판)

PDF 매뉴얼을 근거로 질문에 답하는 챗봇이에요. 노트북 안에서만 돌아가고, 문서 내용은 밖으로 나가지 않아요.
답마다 근거가 된 문서와 쪽 번호를 보여 주고, 누르면 그 쪽이 열려요.

## 테스트 방법 (Windows)

1. 이 폴더를 통째로 원하는 곳에 둡니다. 예: `C:\manual-chatbot`
   - 폴더 경로에 한글이나 공백은 되도록 넣지 마세요.
   - 설치한 다음에는 폴더를 옮기지 마세요. 옮겼다면 `.venv` 폴더를 지우고 `setup.bat` 을 다시 실행하세요.
2. **`setup.bat`** 을 더블클릭합니다. 한 번만 하면 되고, 인터넷으로 약 3.5GB 를 받아서 10~30분쯤 걸려요.
   관리자 권한은 필요 없고, 모든 파일은 이 폴더 안에만 설치돼요.
3. **`docs`** 폴더에 PDF 매뉴얼을 넣습니다. 하위 폴더에 넣어도 돼요.
4. **`run.bat`** 을 더블클릭하면 브라우저에 채팅 화면이 열려요 (`http://127.0.0.1:8000`).
   - 처음에는 AI 모델을 불러오고 문서를 읽느라 1~3분 걸려요. 왼쪽 위 점이 초록색이 되면 질문하세요.
   - 같은 문서는 다음부터 다시 읽지 않아서 빨리 켜져요.
5. 끌 때는 검은 창을 닫으면 돼요.

문서를 더 넣거나 바꿨다면 화면 왼쪽의 **다시 읽기** 를 누르세요.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 켜자마자 '엔진이 꺼졌어요' | 그래픽 가속이 안 맞는 경우예요. `run-cpu.bat` 으로 실행하세요 |
| setup 중 다운로드 실패 | 회사 방화벽이 GitHub·Hugging Face 를 막는 경우예요. 집이나 다른 망에서 setup 을 끝낸 뒤 폴더째 옮기세요 (옮긴 뒤 `.venv` 만 지우고 setup 을 다시 실행) |
| '글자를 찾지 못했어요' | 스캔한 PDF(그림)라서 글자가 없어요. 이번 테스트판에서는 지원하지 않아요 |
| 답이 엉뚱함 | 근거 목록을 펼쳐서 맞는 쪽을 찾았는지 보세요. 못 찾았다면 매뉴얼에 쓰인 낱말로 다시 물어보세요 |

기록은 `data\logs` 폴더에 남아요.

## 구성

| 파일/폴더 | 내용 |
|---|---|
| `app.py` | 문서 읽기, 검색, 답변, 웹 화면을 맡는 프로그램 |
| `static/index.html` | 채팅 화면 |
| `setup.ps1` | 설치 스크립트 (`setup.bat` 이 실행) |
| `engine/` | llama.cpp AI 엔진 (setup 이 받음) |
| `models/chat`, `models/embed` | 답변용 모델, 검색용 모델 (setup 이 받음). 다른 `.gguf` 로 바꿔 넣어도 돼요 |
| `docs/` | 매뉴얼을 넣는 곳 |
| `data/` | 읽어 둔 문서 색인과 기록 |

동작 방식: 문서를 쪽마다 700자 안팎의 조각으로 나눠 두고, 질문이 오면 낱말 검색과 의미 검색을 함께 써서
가장 관련 있는 조각 6개를 찾은 뒤, 그 조각만 근거로 답하게 해요.

설정은 `run.bat` 에서 환경 변수로 바꿀 수 있어요: `GPU_LAYERS`(0 이면 CPU 만), `TOP_K`(근거 조각 수), `PORT`,
`HOST`(`0.0.0.0` 으로 두면 같은 망의 다른 PC 에서도 접속 가능).
